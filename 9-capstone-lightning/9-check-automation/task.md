# Check: Automated Transitions

The through-line of this capstone is 2056's automation-by-sensor. The
binder's FSM diagrams are full of transitions nobody triggers from the
controller — beam breaks, current spikes, timers — alongside a deliberate
few that stay on driver buttons.

Think back through the transition tables you built in tasks 1, 2, 3, 4, and
6. Which of these LIGHTNING transitions fire with **no driver input at
all**? Select every one that qualifies.
